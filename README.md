# Retro Arcade Music Remix

## About My Project

This is my Creative Coding A2 project. I made a short music remix using TunePad.

I chose the song "Electric Rebel" and changed it into a retro arcade style.

The music is around 30 seconds long.

## Tools

- TunePad

## What I Did

- Changed the original melody.
- Made two tracks.
- Changed notes and timing.
- Added comments to my code.

## Files

- `Electric Rebel 8-bit tunepad.json` - My TunePad project
- `Electric Rebel 8-bit.mp3` - My final music

## How to Listen

Open the MP3 file to listen to my music.
Upload the JSON file to TunePad to play the music.
